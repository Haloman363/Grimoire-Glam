# The Grimoire Glam Co

Storefront for resin-printed press-on nails. Product data comes from Square and the site is rebuilt from it automatically.

## Layout
| Path | Purpose |
|---|---|
| `scripts/` | Catalog sync and site build |
| `src/` | Stylesheet and browser scripts |
| `worker/` | Checkout service |
| `config/` | Site settings |
| `assets/` | Fonts, favicon and product photos |

## Commands
```bash
npm ci
npm test
npm run build
npm run dev      # build and serve on http://localhost:8080
```
