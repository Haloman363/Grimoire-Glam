# Brand art

- `character-full.webp`: the full character illustration, no lettering (original upload).
- `character-with-lettering.webp`: the same character with the red and green "Grimoire Glam" lettering (original upload).
- `logo-mark-256.webp` / `logo-mark-512.webp`: square head-and-shoulders crop of `character-full.webp`
  (source pixels x 395-985, y 680-1270). Used for the small round header logo; 512 is for high-DPI or larger uses.
- `logo-character.webp`: transparent-background cutout of the character (head to waist, no lettering, no circle), 512px tall.
  This is the small header logo.
